# 減価償却の月次予算配分

## 意図と受入条件

- 新規作成・修正・日付別経路変更で、費用勘定科目の予算割合を初期値として使える。
- 割合と基準月の金額の双方を手動調整でき、勘定科目の既定値へ戻せる。
- 保存した配分はスナップショットとし、その後の勘定科目設定の変更で履歴を変えない。
- 通貨の最小単位で最大剰余法により分割する。同率は予算ID昇順、未割当は最後とする。各月の振替総額と償却対象額は一致する。
- 金額編集から作る割合を整数％へ丸めない。基準月以外は保存した割合で再配分する。
- 予算割合が100%未満の部分は未割当からの負担として表示し、明示確認を必要とする。100%超過を認めない。
- 既存の単一振替元設定とイベントキーを読み取れる。配分が複数の場合は振替元ごとの対になるイベントを保存する。
- 全ての振替元に対してリセット・アーカイブ・削除の保護が働く。
- プレビューと適用後の結果が一致し、既存の再試行・陳腐化検出・監査記録を維持する。

## 実装範囲

`budget_settings` JSONに配分を追加する。既存のSQLマイグレーションは変更しない。本作業では本番へのpush・デプロイや本番データの変更を行わない。
