# 旧形式の月次予算配分を安全に引き継ぐ

## 意図と受入条件

- 予算設定が保存されていない旧計画でも、根拠が揃った月次仕訳の予算配分だけを安全に認識する。
- 認識条件は、計画の予算方法と設定がともに未設定であること、月次仕訳へのリンクと月番号が一意かつ有効であること、仕訳が他計画の購入元でないこと、仕訳日が計画上の月と一致すること、仕訳ヘッダーの出所がNULLであること。
- 月次仕訳は対象費用科目の借方と対象資産科目の貸方だけからなり、金額と通貨が一致する。仕訳行の作成日時はヘッダーと一致する。
- 対象仕訳の予算配分はすべて出所NULL、参照行ではなく、計画通貨での安全な整数の非正額とする。カテゴリの重複がなく、合計が月次費用と一致し、各行の作成日時が仕訳ヘッダーと一致する。
- 条件から外れる行は曖昧としてプレビュー・適用を拒否し、既存配分を変更しない。NULL出所だけを根拠に認識したり、仕訳や予算設定を自動補完したりしない。
- 正常な旧配分の適用では、旧配分を監査記録に残す処理と旧行の置換を原子的に実施する。月次仕訳行は再作成せず、予算残高に二重計上しない。

## 実装上の境界

認識はGETや通常の会計計算を変更せず、減価償却予算のプレビュー・適用で使う既存の所有配分判定に限定する。既知の `depreciation` 出所の処理と監査・原子的な適用は維持し、根拠が弱い配分は従来どおり曖昧として扱う。スキーマ、保存済みデータ、本番DBには変更を加えず、マイグレーション、push、デプロイも行っていない。
