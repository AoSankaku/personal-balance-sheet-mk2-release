# 予算分割振替の設定継続と月額確認

## 意図と受入条件

- 保存済みの振替先、精算、予算負担終了日は、修正画面を開いたときに読み込まれ、処理方法を切り替えても保持される。
- これら3項目は任意として表示する。振替先や精算が不要なら追加せず、終了日を空欄にすれば既存の月次計画に終了日を追加しない。リセットや精算による実際の予算振替停止はプレビューで確認する。
- 予算設定がない旧計画は、保存済みの購入・月次仕訳の日付と金額を引き継ぎ、予算の扱いが未設定であることを示す。
- 設定画面で実際の月次仕訳日を選び、その月の保存済み仕訳額と予算対象額を確認できる。初期値は今日以降で最も早い仕訳日、完了済みなら最終仕訳日。月選択は予算設定、日付、プレビューの有効性を変更しない。
- 自動作成時の初回日割りと端数処理を説明する。既存仕訳は再計算せず、実際に保存された日付と金額を表示する。
- 金額表示はその通貨の設定済み小数桁と通貨記号を使い、他通貨での保存スケールでは表示しない。

## 実装上の境界

一覧APIの金額単位を一度だけ利用者通貨へ戻し、修正画面では設定済み小数桁と有効な通貨記号で表示する。月額の確認は保存済み仕訳額を使う。初回を日割りし端数を初回へ加える規則は自動作成時の説明として示すだけで、既存の月次仕訳は再計算しない。実際の予算受取額は、振替先、精算、終了日、リセットを反映したプレビューで確認する。

データベーススキーマ、会計計算、保存済みデータは変更しない。本番DBは依頼された金額の根拠を確認するために読み取りのみ実施した。マイグレーション、本番データへの書き込み、push、デプロイは行っていない。検証用APIとブラウザーは終了し、既存の開発サーバーは維持した。
