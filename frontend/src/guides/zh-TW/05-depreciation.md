# 預算分期轉帳（折舊）

此功能會將採購成本分攤為每月支出，並按月管理對預算的影響。採購時，金額會先記入選定的「購買資產帳戶」，再依設定期間轉入「支出帳戶」。購買資產帳戶中的剩餘餘額代表計畫中尚未轉為支出的金額，不代表採購品的市場價值或稅務價值。

例如，一臺 120,000 日圓的電腦分 12 個月處理時，每月約有 10,000 日圓從購買資產帳戶轉入支出帳戶。若啟用每月預算補充，也會每月從一般預算類別轉帳到採購預算。

## 預算處理方式

| 方式 | 採購時及每月的預算處理 |
| --- | --- |
| 已分配預算 | 採購時減少所選的採購預算。之後每月依設定比例從預算來源轉帳到採購預算進行補充。 |
| 特別預算 | 專用的特別預算從負餘額開始。之後每月依設定比例從預算來源轉帳到特別預算進行補充。 |
| 未分配 | 採購時由未分配資金負擔計入預算的採購金額。每月支出分錄仍會繼續，但不會進行每月預算補充。 |

## 輸入與預算比例

請先前往設定 > 帳戶，新增資產帳戶，並勾選「不納入預算，並作為預算分期轉帳（折舊）的來源資產帳戶」。該帳戶不計入預算，用於記錄採購金額並作為每月轉帳的來源。

在輸入頁面啟用「預算分期轉帳（折舊）」，選擇新建的「購買資產帳戶」和「支出帳戶」，並以「轉帳月數」或「每月轉帳金額」設定期間。對於每月補充預算的方式，「預算比例」編輯器會以支出帳戶的預算比例作為初始值。每項已儲存的計畫都會保留比例快照，因此日後修改支出帳戶不會改變既有計畫。

可直接編輯各預算類別的比例，也可輸入編輯器顯示的代表月份金額來調整。輸入金額會依該代表性轉帳設定比例；實際轉帳金額可能因月份而異，例如首月按比例折算。「還原費用科目的預設比例」會重新載入該帳戶目前的預算比例。

若具名類別的比例總和低於 100%，剩餘部分會視為從未分配資金轉出；儲存前需要明確確認。比例總和超過 100% 時無法儲存。從未分配資金轉出的部分會減少這些資金，同時補充採購預算。

餘數會按貨幣最小單位使用最大餘數法分配。同餘時依預算類別 ID 升冪處理，未分配資金最後處理。每月預算來源總額會與補充至採購預算的金額一致。

## 編輯與刪除

修改採購或計畫設定可能影響每月支出分錄和預算補充。請從原始採購輸入或計畫設定中修改，不要直接編輯自動產生的每月分錄或預算記錄。不再需要時，請刪除相關計畫。

## 本記帳簿中的處理方式

此功能供家庭記帳使用，將採購成本分攤為每月支出，並透過預算類別間的轉帳管理每月預算影響。購買資產帳戶中的剩餘餘額代表計畫中尚未轉為支出的金額。此功能不會判定資產的市場價值、耐用年限、折舊方法、業務使用比例或稅務處理。正式會計或稅務處理應依適用規則另行管理。
