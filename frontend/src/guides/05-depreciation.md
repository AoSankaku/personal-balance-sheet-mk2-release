# 予算分割振替

購入額を複数月に分けて費用に振り替え、予算上の負担も月ごとに管理する機能です。購入時はいったん「購入資産科目」に記録し、設定した期間に「費用科目」へ費用を振り替えます。購入資産科目に残る残高は計画上の未費用化額であり、購入品の市場価値や税務上の資産価値を示すものではありません。

たとえば12万円のパソコンを12か月で振り替えると、購入資産科目から費用科目へ毎月およそ1万円ずつ費用を振り替えます。月次の予算補填を設定すると、通常の予算カテゴリから購入時の負担予算へも月ごとに振り替えます。

## 予算の扱い方

| 方法 | 購入時と月次の予算処理 |
| --- | --- |
| 割当済み予算 | 購入時に選んだ負担予算を減らし、毎月、予算割合で指定した振替元から負担予算へ振り替えて補填します。 |
| 特別予算 | 購入専用の特別予算をマイナスにし、毎月、予算割合で指定した振替元から特別予算へ振り替えて補填します。 |
| 未割当 | 購入時の予算対象額を未割当資金（U）から負担します。月次の費用仕訳は続きますが、月次の予算補填は行いません。 |

## 入力と予算割合

入力ページで「予算分割振替」を有効にし、「購入資産科目」「費用科目」と期間を設定します。期間は「振替月数」または「毎月の振替額」で指定できます。月次の予算補填を行う方法では、「予算割合」に費用科目の予算割合が初期値として表示されます。保存した計画には割合のスナップショットが記録されるため、あとから費用科目の設定を変更しても既存計画の割合は変わりません。

予算割合は、予算カテゴリごとに割合を直接入力するか、画面に表示される代表月の金額を編集して調整できます。金額を入力すると、その代表月の振替額を基準に割合が設定されます。実際の振替額は初月の日割りなどで月ごとに変わることがあります。「勘定科目の予算割合を復元」で、費用科目の現在の予算割合を読み直せます。

名前付きカテゴリの割合が合計100%未満の場合、残りは未割当資金（U）からの振替分として扱われ、保存には明示的な確認が必要です。100%を超える割合は保存できません。Uから振り替えた分は未割当資金を減らし、購入時の負担予算を補填します。

端数は通貨の最小単位で最大剰余法により配分します。同率の場合は予算カテゴリIDの昇順で配り、Uを最後に扱います。各月の振替元の合計は、購入時の負担予算への補填額と一致します。

## 編集と削除

購入仕訳や計画設定を変更すると、月次費用仕訳や予算補填の内容にも影響します。元の購入入力または計画設定から変更し、自動生成された月次仕訳や予算記録を直接編集しないでください。計画が不要になった場合は、関連する設定から削除してください。

## 減価償却との違い

この機能は、家計管理のために購入費用を分割して記録し、予算カテゴリ間の振替で月ごとの負担を管理します。購入資産科目に残る金額は、計画上まだ費用に振り替えていない額です。資産の市場価値、耐用年数、償却方法、事業割合、税務上の扱いを判定する正式な減価償却ではありません。必要な会計・税務処理は、適用されるルールに従って別途管理してください。
