# 预算分期转账

此功能将购买成本分摊为每月支出，并按月管理其对预算的影响。购买时，金额先记入选定的“购买资产账户”，再按设定期间转入“支出账户”。购买资产账户中的剩余余额表示计划中尚未转为支出的金额，不代表购买品的市场价值或税务价值。

例如，一台12万日元的电脑分12个月处理时，每月约有1万日元从购买资产账户转入支出账户。如果启用了每月预算补充，还会从常用预算类别向购买预算转入资金。

## 预算处理方式

| 方式 | 购买时和每月的预算处理 |
| --- | --- |
| 已分配预算 | 购买时减少所选的购买预算。之后每月按设定比例从预算来源转账到购买预算，进行补充。 |
| 特别预算 | 专用特别预算从负余额开始。之后每月按设定比例从预算来源转账到特别预算，进行补充。 |
| 未分配 | 购买时由未分配资金（U）承担计入预算的购买金额。每月支出分录仍会继续，但不会进行每月预算补充。 |

## 输入与预算比例

在输入页面启用“预算分期转账”，选择“购买资产账户”和“支出账户”，并通过“转账月数”或“每月转账金额”设置期间。对于每月补充预算的方式，“预算比例”编辑器会以支出账户的预算比例作为初始值。每项已保存的计划都会保留比例快照，因此以后修改支出账户不会改变现有计划。

可以直接编辑每个预算类别的比例，也可以输入编辑器显示的代表月份金额来调整。输入金额会根据该代表性转账设定比例；实际转账金额可能因月份不同而变化，例如首月按比例折算。“恢复费用科目的默认比例”会重新载入该账户当前的预算比例。

如果具名类别的比例总和低于100%，剩余部分会视为从未分配资金（U）转出；保存前需要明确确认。比例总和超过100%时无法保存。U部分会减少未分配资金，同时补充购买预算。

余数会按货币最小单位使用最大余数法分配。余数相同时按预算类别ID升序处理，U最后处理。每月预算来源总额会与补充到购买预算的金额一致。

## 编辑与删除

修改购买或计划设置可能影响每月支出分录和预算补充。请从原始购买输入或计划设置中修改，不要直接编辑自动生成的月度分录或预算记录。不再需要时，请删除相关计划。

## 与折旧的区别

此功能用于家庭记账，将购买成本分摊为每月支出，并通过预算类别间的转账管理每月预算影响。购买资产账户中的剩余余额表示计划中尚未转为支出的金额。此功能不会判定资产的市场价值、使用年限、折旧方法、业务使用比例或税务处理。正式会计或税务处理应根据适用规则另行管理。
