# 预算系统（虚拟桶）

预算类别是叠加在实际现金和银行账户之上的虚拟桶。实际账户余额保持不变，而预算系统按用途分配这些资金，例如自由支出、必要支出、旅行基金或投资储备。

## 核心概念

| 项目 | 作用 |
| --- | --- |
| 账户 | 实际账簿项目，如银行账户、信用卡、工资或餐饮支出 |
| 预算类别 | 基于用途的现金/存款虚拟桶 |
| 关联支出账户 | 决定哪些支出分录消耗预算 |
| 目标持有账户 | 描述您打算将预算资金存放在何处 |

从设置 -> 预算设置创建类别。一个类别可以有分组、目标余额、余额上限、溢出目的地、关联支出账户和目标持有账户。

## 滚动、重置和上限

常规预算无论正负都会全额结转。负预算表示超支，但由于现金流出已反映该超支，因此不会再次计入预算占用，也不会增加可分配资金。

如果历史导入或修正使余额变得不现实，请使用输入 -> 预算调整 -> 预算重置将该类别归零。概览页面会在当月显示一个带日期的重置徽章。余额上限可以将多余预算发送到另一个类别。

## 收入分配和调整

收入条目可以应用预算过滤器，将存入资金分配到各个类别。过滤器使用固定金额、上限和比例分配步骤。后续的手动预算调整可以增加或减少单个类别，并可以包含可选备注。

在“录入 > 预算调整”中，可以查看所有预算，选择要调整的预算，并将列表筛选为仅显示所选项。可一次录入多项增加和减少，并共用一个日期和备注。查看各项预算调整前后的余额，以及按所选日期精确计算的调整后可分配金额。调整额合计不必为零：预算 A 调整 −10,000，预算 B 调整 +8,000，合计为 −2,000。补足负数预算以及上限超出后的转出，可能导致可分配金额的变化与调整额合计不同。计算进行中或结果不可用时无法保存。如果余额发生变化，请先检查更新后的计算结果，再重新保存。切换到“重置预算”可使用原有的余额归零流程。

## 预算布局

现金/银行账户有一个"包含在可分配预算来源中"的设置。只有启用的账户才会计入可分配现金和预算布局中的实际余额。

预算布局表出现在设置 -> 预算设置和财务报表 -> 预算 -> 预算一致性检查中。

| 显示 | 含义 |
| --- | --- |
| 目标 | 账户组预期的预算余额 |
| 实际 | 目标账户的实际现金/银行余额 |
| 差额 | 实际 - 目标 |

目标金额采用与可分配资金相同的规则：只合计各类别的正预算余额。负预算余额不会抵减目标，而是作为“未弥补的预算超支”单独显示。在预算页面中可以切换“截至今天”和“包含未来收入”两种口径；资金缺口通知会打开截至今天的视图。

如果一个预算关联多个账户，或多个预算关联一个账户，相关的预算和账户会合并成一个组。存在差额时，提示会显示需要在账户组之间转移多少资金，或需要增加或减少多少预算。

## 转账和预算移动

在简易输入中输入账户转账时，您可以选择同时移动预算。选择源和目标预算类别记录预算转移，或将目标留空以消耗/消失预算，例如将预留资金用于投资时。

实际转账和预算移动是独立的事件。预算-账户关联是布局指导；它们不会强制收入分配和银行转账同时发生。

## 预算一致性 {#budget-reconciliation}

预算 -> 预算一致性检查检测分录金额与已保存的预算分配金额之间的不匹配。对于多行分录和预算跟踪之外的交易，除非保存了明确的分配，否则应用不会猜测预算类别。

将鼠标悬停在详细计算中的“？”图标上，或用键盘聚焦该图标，即可查看简短说明。点击该图标，或在触屏上轻点，可打开本指南对应部分。

比较时请使用相同的币种和时间范围。“截至今天”与“包含未来收入”使用的数据不同。下方日记账问题列表的日期筛选不会改变上方的整体计算。

### 预算可用现金资源（C） {#budget-resources}

已计入预算来源的现金和银行余额，减去需要从预算中扣除的负债。默认扣除信用卡欠款。不包括已排除的现金账户、购入资产和投资。虽然标签提到现金，此数值已扣除所选负债。

### 全部预算余额（包含负数）（N） {#budget-net-balance}

所有类别余额的总和，包括负余额。若 P 为正预算需求，O 为未弥补的预算超支，则 `N = P − O`。

### 纯整合差额（G） {#budget-net-gap}

`G = C − N`。正数表示资金资源多于净预算余额；负数表示预算余额多于资金资源。未分配资金、预留金额和非现金费用调整也会造成差额，因此非零并不一定代表输入错误。

### 非跟踪支出预留额（R） {#budget-reference-reserve}

用于单独预留非跟踪支出的字段，目前为零；参考记录不会占用常规预算。转入排除账户的金额和参考记录金额不会自动填入此字段。

### 剩余购入预留额 {#budget-purchase-reserve}

购入时设置的预留额中，尚未用于月度费用确认的部分。购入时已经影响预算余额，因此不会再次从纯整合差额中扣除。重置会清除之前的预留。

### 重置后的月度非现金费用抵扣（D） {#budget-non-cash-offset}

重置清除购入预留后，月度费用确认可能在没有新增现金支付的情况下减少预算。此抵扣可防止这项减少变成新的可分配资金。按类别累计“现金支出基准正余额 − 常规正余额”的正值部分；它可能不同于月度费用总额。

### 扣除预留后的整合差额（A） {#budget-adjusted-gap}

`A = G − R − D`。从纯整合差额中扣除非跟踪支出预留额和非现金费用抵扣。不要再次扣除剩余购入预留额。如果 R 和 D 均为零，A 等于 G。仍为负数可能表示资金减少却没有记录相应的预算减少；正数可能包含未分配资金。

### 正预算需求额（P） {#budget-positive-claims}

只合计正的类别余额，不与负类别余额抵销。它表示要让所有正预算都能使用所需的资金。

### 已确保金额（S） {#budget-secured}

`S = P + R + D`。正预算需求额加上预留额和非现金费用抵扣。

### 新增可分配金额／预算资金缺口（F） {#budget-funding-gap}

`F = C − S = A − O`。结果大于或等于零时表示还有新增可分配资金；负数表示预算资金不足。即使整合差额为零，只要仍有负预算余额，就会产生同等金额的资金缺口。超支造成的现金减少已经反映在 C 中，不要再次从 F 扣除 O。

### 未弥补的预算超支（O） {#budget-overspending}

负类别余额绝对值的总和。可从其他预算补足，或分配之后的收入。类别之间移动相同金额不会改变 N，因此也不会改变 G。

### 与预算配置过剩／不足的区别 {#budget-placement-gap}

预算配置过剩／不足是保管账户中的现金减去该处所需的正预算、预留额和抵扣。这里尚未扣除信用卡欠款等负债。“转账后”一栏估算为平衡预算配置而提出的转账方案执行后的结果；“扣除信用卡欠款后”的合计也扣除了相关负债。转账可以改变单个账户的差额，但只在纳入预算的账户之间转移资金，并不能解决整体整合差额。

虚构示例：现金 `100,000`，可扣除的信用卡欠款 `10,000`，类别余额 `100,000` 和 `−15,000`，R 为 `2,000`，D 为 `3,000`。当前 R 为零。

| 项目 | 计算 |
| --- | --- |
| 资源 C | 100,000 − 10,000 = 90,000 |
| 净预算 N | 100,000 − 15,000 = 85,000 |
| 纯整合差额 G | 90,000 − 85,000 = 5,000 |
| 扣除后差额 A | 5,000 − 2,000 − 3,000 = 0 |
| 已确保金额 S | 100,000 + 2,000 + 3,000 = 105,000 |
| 资金缺口 F | 90,000 − 105,000 = −15,000 |
| 配置差额合计 | 100,000 − 105,000 = −5,000 |

此例中整合差额为零，但未弥补的预算超支是 `15,000`，资金缺口为 `−15,000`。配置差额 `−5,000` 尚未扣除信用卡欠款，因此与资金缺口不同。

### 检查转入排除账户的转账 {#budget-excluded-transfers}

如果收到未跟踪的现金，同时从已纳入的银行账户汇出同额资金，家庭资产只是交换了形式，但预算资源 C 会减少。如果没有记录同额的预算减少，N 不变，G 和 A 会减少。在简易输入中，将承担支出的预算选作“预算转出方”，并把“预算转入方”选为“消灭”，即可减少预算。只在类别之间转移不会减少 N。

即使没有费用科目，检查也会提示转入排除账户的转账缺少预算减少。在同时含费用和转入排除账户的复合分录中，检查会考虑已保存的预算减少。如果有意使用未分配资金，资源减少会消耗这部分余额；检查提示不会自动减少任何预算。
