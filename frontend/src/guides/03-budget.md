# 予算システム（仮想バケット）

予算カテゴリは勘定科目ではなく、現金・預金の上に重ねる目的別の仮想バケットです。銀行口座の実残高はそのままに、「自由出費」「必要出費」「旅行準備金」「投資準備金」などの使い道別に残高を管理します。

## 基本構造

| 種類 | 役割 |
| --- | --- |
| 勘定科目 | 帳簿に記録される実体。銀行口座、カード、給与、食費など |
| 予算カテゴリ | 現金・預金の使い道を分ける仮想枠 |
| 費用科目との連携 | 支出入力時に、どの予算を消費するかを決める |
| 目標保管口座 | 予算をどの現金・預金口座に置く想定かを示す |

設定 -> 予算設定でカテゴリを作成します。名前、グループ、目標額、上限額、上限超過時の移動先、連携する費用科目、目標保管口座を設定できます。

## 繰越、リセット、上限

通常予算は、プラスでもマイナスでも全額繰り越します。マイナス予算は過去の超過ですが、現金の減少にすでに反映されているため、予算拘束額として重ねて差し引きません。また、予算可能額を増やすこともありません。

過去データの投入や大きな補正で残高が崩れた場合は、入力 -> 予算調整の「予算リセット」で対象カテゴリを0にできます。概要ページでは、リセットがあった月に日付付きバッジが表示されます。

上限額を設定したカテゴリでは、上限を超えた分を別の予算カテゴリへ回せます。

## 収入配分と予算調整

収入入力時は、予算フィルターで入金額を複数カテゴリへ配分できます。フィルターは固定額、上限付き、割合配分のステップで構成します。あとから予算調整で個別に増減でき、調整には任意コメントを残せます。

配分先の配置口座が入金口座と異なる場合は、口座移動タスクが作成されます。複数の未完了タスクがあるときは、口座ごとの純増減を差し引いて、実際の振替が最小本数になる組み合わせを確認・一括完了できます。異なる通貨の移動は別々に計算されます。

## 予算配置

現金・預金科目には「予算割り当て元に含める」設定があります。ONの口座だけが、予算可能額と予算配置の実残高に含まれます。

予算配置表は、設定 -> 予算設定と、財務諸表 -> 予算 -> 予算整合性チェックに表示されます。

| 表示 | 意味 |
| --- | --- |
| 目標額 | その口座グループに置く想定の予算残高 |
| 実残高 | 対象の現金・預金口座の実残高 |
| 差分 | 実残高 - 目標額 |

目標額には、配分可能額と同じく各カテゴリの正の予算残高だけを合計します。負の予算残高は目標額を減らさず、「未補填の予算超過」として別枠に表示されます。予算ページでは「本日時点」と「将来入金を含む」を切り替えられ、右上の不足通知からは本日時点の予算配置へ移動します。

1つの予算が複数口座に紐づく場合、または複数予算が1つの口座に紐づく場合は、関連する予算と口座をひとつのグループとして合算します。差分がある場合は、どこからどこへいくら移動するか、または追加で割り当てる・減らすべきかのヒントが表示されます。

## 振替と予算移動

シンプル入力で口座間振替を入力するとき、必要に応じて予算も同時に移動できます。送金元カテゴリと送金先カテゴリを選ぶと予算移動として記録され、送金先を空にすると投資実行などで予算が消滅した扱いにできます。

実際の口座振替と予算移動は別イベントです。予算と口座の紐づけは配置確認のための情報であり、収入配分や預金移動を自動で強制するものではありません。

## 予算整合性 {#budget-reconciliation}

支出・収入の仕訳額と保存された予算配分額がずれると、予算ページの予算整合性チェックで検出できます。複合仕訳や予算対象外取引には、明示的な配分がない限り予算カテゴリを自動適用しません。

「整合性の詳しい計算を見る」では、資金と予算の対応を次の用語で確認できます。各項目の「？」にマウスを重ねるかキーボードでフォーカスすると短い説明が表示され、クリックするとこのガイドの該当箇所へ移動します。タッチ操作では「？」をタップしてください。

同じ通貨・同じ時点の数値を比較してください。「本日時点」と「将来入金を含む」では対象データが異なります。下の仕訳一覧の日付フィルターは、上部の全体計算の期間を変更しません。

### 予算原資の現預金（C） {#budget-resources}

予算割り当て元に含めた現金・預金の合計から、「予算から控除する」負債の残高を引いた額です。カード未払は初期設定で控除対象です。予算対象外の現金・預金、購入資産や投資資産は含みません。表示名に「現預金」とありますが、カード未払などを差し引いた後の額です。

### 全予算残高（負を含む）（N） {#budget-net-balance}

各予算カテゴリの残高を、マイナスも含めて合計した額です。正の予算要求額を P、未補填の予算超過を O とすると、`N = P − O` です。

### 純整合差額（G） {#budget-net-gap}

`G = C − N`。予算原資と、負を含む全予算残高との差です。プラスは予算残高より原資が多く、マイナスは原資より予算残高が多いことを表します。未割当資金や下記の予約・非現金費用でも差が生じるため、0以外の値がすべて入力ミスとは限りません。

### 非追跡支出の予約額（R） {#budget-reference-reserve}

非追跡支出向けに別途確保する額を表す欄です。現在の計算では0で、参考記録は通常の予算使用額に含まれません。予算対象外口座への送金額や、参考記録の合計が自動的にこの欄へ入るわけではありません。

### 購入時予約の残額 {#budget-purchase-reserve}

予算分割振替（減価償却）の購入時に予約した額のうち、月次の費用化にまだ充てていない残りです。購入時にすでに予算残高へ反映済みなので、純整合差額からこの残額をもう一度差し引くことはありません。リセットで以前の予約はクリアされます。

### リセット後の月次非現金費用（D） {#budget-non-cash-offset}

予約がリセットで消えた後の月次費用化は、新たな現金支出を伴わずに予算残高を減らすことがあります。この減少を新しく割り当てられる資金にしないための補正額です。カテゴリごとに「現金支出基準の正の残高 − 通常計算の正の残高」の正の部分を合計します。月次費用の総額そのものとは限りません。

### 予約控除後の整合差額（A） {#budget-adjusted-gap}

`A = G − R − D`。純整合差額から非追跡支出の予約額と月次非現金費用の補正額を引いた結果です。「購入時予約の残額」は追加で引きません。R と D がともに0なら、純整合差額と同額です。マイナスが残るときは、原資の減少に対応する予算減少の未記録などを確認します。プラスには未割当資金が含まれることがあります。

### 正の予算要求額（P） {#budget-positive-claims}

プラスのカテゴリ残高だけを合計した額です。マイナスのカテゴリで相殺しません。すでにある正の予算を全額使えるようにするために必要な資金を表します。

### すでに確保済み（S） {#budget-secured}

`S = P + R + D`。正の予算要求額に予約額と非現金費用の補正額を足した額です。

### 新たに割り当て可能・予算原資の不足（F） {#budget-funding-gap}

`F = C − S = A − O`。0以上なら「新たに割り当て可能」、マイナスなら「予算原資の不足」と表示します。整合差額が0でも、マイナスのカテゴリが残っていれば、その超過額だけ原資不足になります。超過支出による現金減少は C に反映済みなので、F から O をさらに差し引くことはありません。

### 未補填の予算超過（O） {#budget-overspending}

マイナスのカテゴリ残高の絶対値を合計した額です。別の予算から補填するか、後の収入を配分して解消します。予算カテゴリ間で同額を移しても全予算残高 N は変わらず、純整合差額 G も変わりません。

### 予算配置の「過不足」との違い {#budget-placement-gap}

配置表の「過不足」は、対象の現金・預金残高から、その保管先で必要な正の予算と予約・補正額を引いた値です。この段階ではカード未払などの負債を引いていません。「口座移動後」は配置調整のために提案された移動を実行した場合の見込み、「カード未払控除後」は合計に負債の控除も反映した値です。個々の保管先の過不足は口座間移動で変わりますが、予算対象の口座間で移すだけでは全体の整合差額は解消しません。

たとえば現預金が `100,000`、控除するカード未払が `10,000`、予算残高が `100,000` と `−15,000`、R が `2,000`、D が `3,000` の場合、次のようになります（説明用の仮の数値です。現在の R は0です）。

| 項目 | 計算結果 |
| --- | --- |
| 原資 C | 100,000 − 10,000 = 90,000 |
| 全予算残高 N | 100,000 − 15,000 = 85,000 |
| 純整合差額 G | 90,000 − 85,000 = 5,000 |
| 予約控除後 A | 5,000 − 2,000 − 3,000 = 0 |
| 確保済み S | 100,000 + 2,000 + 3,000 = 105,000 |
| 原資不足 F | 90,000 − 105,000 = −15,000 |
| 配置の過不足（合計） | 100,000 − 105,000 = −5,000 |

この例では整合差額は0ですが、未補填の予算超過は `15,000`、原資不足は `−15,000` です。配置の過不足 `−5,000` はカード未払の控除前なので、原資不足とは異なります。

### 予算対象外口座への振替を確認する {#budget-excluded-transfers}

追跡しない現金を受け取り、同額を予算対象の銀行口座から送った場合、家計全体では交換でも、予算に使える原資 C は減ります。原資の減少と同額の予算減少を記録しなければ N は変わらず、G と A がマイナスになります。シンプル入力の「予算送金元」で負担予算を選び、「予算送金先」を「消滅」にすると予算を減らせます。カテゴリ間の移動だけでは N の合計は減りません。

費用科目のない対象外口座への振替でも、対応する予算減少が不足していればチェックに表示します。費用と対象外口座への移動を含む複合仕訳では、保存済みの予算減少を含めて判定します。意図的に未割当資金から負担する場合は、原資の減少で未割当の余裕を使うため、チェックの指摘だけで予算を自動的に減らすことはありません。
